# Day 34 – NCBI Gene: TP53

## Objective
To explore the NCBI Gene database and understand the basic information associated with the human TP53 gene.

## Database
NCBI Gene

## Gene Details
- **Gene Name:** Tumor protein p53
- **Gene Symbol:** TP53
- **Gene ID:** 7157
- **Organism:** Homo sapiens (human)
- **Chromosome Location:** 17p13.1
- **Gene Type:** Protein-coding
- **Reference mRNA:** NM_000546.6

## Gene Summary
TP53 encodes the p53 tumor suppressor protein, which helps regulate cell growth and respond to DNA damage. TP53 mutations are associated with several types of cancer.

## FASTA Sequence
The TP53 mRNA reference sequence was explored using NCBI RefSeq.

- **Accession:** NM_000546.6
- **Sequence Type:** mRNA
- **Source:** NCBI Nucleotide / RefSeq

## Key Learnings

- Identified the gene symbol and Gene ID.
- Learned about chromosome location and gene function.
- Explored the reference mRNA record and FASTA sequence format.
