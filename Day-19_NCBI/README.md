# Day 19 – NCBI

## What is NCBI?

NCBI (National Center for Biotechnology Information) is a major biological information resource that provides access to genomic, genetic, protein and biomedical data.

## Important NCBI Resources

| Resource | Main Use |
|----------|----------|
| NCBI Gene | Gene information |
| GenBank | DNA/RNA sequence records |
| BLAST | Sequence similarity search |
| Protein | Protein sequence information |
| PubMed | Scientific research papers |
| Genome | Genome information |
| ClinVar | Clinical significance of genetic variants |

## Basic Bioinformatics Workflow

Gene → GenBank → BLAST → UniProt → ClinVar

## Key Takeaway

NCBI provides multiple biological databases and tools that help researchers search, retrieve and analyze biological information.
