# Day 04 – Proteins & Amino Acids

Today I learned how amino acids form proteins and how proteins become functional after folding.

## Topics Covered

### Amino Acid
- Building block of proteins.
- Has four main parts: NH₂, COOH, H, and R group.
- There are 20 common amino acids.

### Peptide Bond
- A chemical bond that connects two amino acids.
- Water (H₂O) is released during this process (dehydration reaction).

### Polypeptide
- A long chain formed by many amino acids connected through peptide bonds.

### Protein Folding
- A polypeptide folds into a 3D shape to become a functional protein.
- Chaperone proteins help prevent incorrect folding.

### Protein Functions

| Protein | Function |
|---------|----------|
| Keratin | Hair and Nails |
| Collagen | Skin support |
| Actin | Muscle movement |
| Myosin | Muscle movement |
| Hemoglobin | Oxygen transport |
| Antibodies | Fight bacteria and viruses |
| Insulin | Cell signaling |

## Learning Flow

Amino Acid → Peptide Bond → Polypeptide → Protein Folding → Functional Protein
