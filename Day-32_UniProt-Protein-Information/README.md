# Day 32 – UniProt: Protein Information

## What is UniProt?

UniProt (Universal Protein Resource) is a database that provides information about proteins.

## Important Information in UniProt

| Topic | What to Learn |
|---|---|
| Protein Name | Official name of the protein |
| Organism | Species in which the protein is found |
| Gene | Gene that produces the protein |
| Amino Acid Sequence | Sequence of amino acids in the protein |
| Function | Main role of the protein |
| Disease | Diseases associated with the protein, where documented |

## Why is UniProt Important?

- Helps researchers understand protein functions.
- Provides amino acid sequences.
- Connects proteins with genes and organisms.
- Supports research into diseases and human health.

## Key Takeaway

UniProt helps us explore protein names, organisms, genes, amino acid sequences, functions, and disease associations.
