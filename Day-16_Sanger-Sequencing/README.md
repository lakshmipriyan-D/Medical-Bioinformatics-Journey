# Day 16 – Sanger Sequencing

## What is Sanger Sequencing?

Sanger Sequencing is a DNA sequencing method also called the **chain-termination method**.

## Main Principle

Sanger sequencing uses **ddNTPs (dideoxynucleotides)** to stop DNA strand extension at specific points.

## Basic Workflow

DNA Template → Primer → DNA Polymerase → dNTP + ddNTP → Chain Termination → DNA Sequence

## Key Point
