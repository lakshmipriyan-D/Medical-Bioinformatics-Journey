# Day 21 – Proteomics

## What is Proteomics?

Proteomics is the large-scale study of proteins in a biological system.

## What is a Protein?

A protein is a biological molecule made up of amino acids that performs various functions in cells.

## What is a Proteome?

A proteome is the complete set of proteins produced by a cell, tissue, or organism at a particular time or condition.

## Proteome vs Genome

| Genome | Proteome |
|---|---|
| Complete set of DNA/genetic information | Complete set of proteins |
| Relatively stable | Changes with time and conditions |
| Contains genes | Contains proteins |
| Studied using genomics | Studied using proteomics |

## Key Takeaway

**Genome = genetic information**

**Proteome = proteins produced from that information**
