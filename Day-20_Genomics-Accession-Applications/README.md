# Day 20 – Accession Number and Applications of Genomics

## Accession Number

An **Accession Number** is a unique identifier given to a biological sequence or database record. It helps researchers find and refer to the same record easily.

## Applications of Genomics

### 1. Disease Gene Detection
Genomics helps identify genes and genetic variants associated with diseases.

### 2. Personalized Medicine
Genomic information can help select treatments based on an individual's genetic profile.

### 3. Cancer Genomics
Genomics helps identify mutations and genetic changes involved in cancer.

### 4. Forensic Science
DNA analysis is used for identification and forensic investigations.

### 5. Agriculture
Genomics helps improve crops and livestock by studying useful genetic traits.

### 6. Virus Tracking
Genomic sequencing helps track genetic changes and transmission of viruses.

## Key Takeaway

Genomics helps us understand genetic information and apply it in healthcare, forensic science, agriculture, and disease surveillance.
