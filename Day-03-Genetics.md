# Day 03 – Genetics

Today I completed the core concepts of Genetics and inheritance.

## Topics Covered

### Genetics
- Study of how traits are inherited from parents to children.
- Traits are characteristics passed from one generation to the next.

### Gene & Allele

| Term | Meaning |
|------|---------|
| **Gene** | An instruction in DNA that controls a trait. |
| **Allele** | Different versions of the same gene inherited from each parent. |

### Dominant vs Recessive

| Dominant | Recessive |
|-----------|-----------|
| Produces a working enzyme. | Does not produce a working enzyme. |
| One copy is enough for the trait to appear. | The trait appears only when both alleles are recessive. |

### Homozygous & Heterozygous

| Type | Genotype |
|------|----------|
| Homozygous Dominant | `AA` |
| Heterozygous | `Aa` |
| Homozygous Recessive | `aa` |

### Genotype vs Phenotype

| Genotype | Phenotype |
|----------|-----------|
| `AA` | Dominant trait |
| `Aa` | Dominant trait |
| `aa` | Recessive trait |

- **Genotype:** Genetic combination (`AA`, `Aa`, `aa`).
- **Phenotype:** Visible trait or physical appearance.

### Punnett Square
- A 2×2 chart used to find possible offspring genotypes and their probabilities.
- **Gamete Rule:**
  - `AA → A, A`
  - `Aa → A, a`
  - `aa → a, a`

### Mutation

A mutation is a permanent change in the DNA sequence.

| Type | What Happens |
|------|--------------|
| **Substitution** | One DNA letter is replaced. |
| **Insertion** | An extra DNA letter is added. |
| **Deletion** | A DNA letter is removed. |

### Mutation Effects

| Effect | Meaning |
|--------|---------|
| **Neutral** | DNA changes, but there is no effect on the body. |
| **Harmful** | Can cause diseases such as Sickle Cell Disease. |
| **Beneficial** | Can provide an advantage, such as lactose tolerance. |

## Learning Flow

Trait → Gene → Allele → Dominant/Recessive → Homozygous/Heterozygous → Genotype → Phenotype → Punnett Square → Mutation
