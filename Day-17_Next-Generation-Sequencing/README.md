# Day 17 – Next-Generation Sequencing (NGS)

## What is NGS?

Next-Generation Sequencing (NGS) is a modern sequencing technology that allows many DNA fragments to be sequenced in parallel.

## Basic Working Process

DNA Sample
→ Fragmentation
→ Library Preparation
→ Sequencing
→ Sequence Reads
→ Data Analysis

### 1. DNA Extraction

DNA is isolated from the biological sample.

### 2. Library Preparation

DNA is fragmented and sequencing adapters are added to prepare the DNA for sequencing.

### 3. Sequencing

The prepared DNA library is loaded into a sequencing instrument.

In Illumina sequencing, bases are detected as they are incorporated into growing DNA strands.

### 4. Data Analysis

The sequencer produces sequence reads.

Bioinformatics tools are then used to process and analyze these reads.

## Key Takeaway

NGS allows large numbers of DNA fragments to be sequenced in parallel, making it possible to analyze large amounts of genetic information efficiently.
