# Day 36 – BLAST Sequence Analysis

## Objective
To perform nucleotide sequence similarity analysis using NCBI BLAST and understand the results.

## Tool
NCBI Nucleotide BLAST (BLASTN)

## Query Details
- **Query:** DNA nucleotide sequence
- **Query length:** 480 bp
- **Database:** core_nt
- **Program:** BLASTN

## 1. BLAST Search Results
The BLAST results page displays matching sequences and alignment statistics, including query coverage, percentage identity, and E-value.

![BLAST Search Results](01-BLAST-Results.png)

## 2. Pairwise Sequence Alignment
The pairwise alignment view helps compare matching nucleotide positions between the query and a database sequence.

![BLAST Pairwise Alignment](02-BLAST-Pairwise-Alignment.png)

## Key Learnings
- Learned how to submit a nucleotide sequence to BLAST.
- Explored sequence similarity search results.
- Understood percentage identity, query coverage, and E-value.
- Viewed a pairwise nucleotide alignment.

## Interpretation Note
The displayed result includes a short alignment with 100% identity across 29 aligned nucleotides, 6% query coverage, and an E-value of 0.017. This is a short, partial match and does not establish biological or clinical significance by itself.

## Learning Outcome
This practical introduced the use of BLAST for sequence similarity analysis and interpretation of alignment statistics.
