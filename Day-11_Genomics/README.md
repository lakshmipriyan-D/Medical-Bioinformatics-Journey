# Day 11 – Genomics

## What is Genomics?

Genomics is the study of an organism's **entire genome**, including all of its genes and DNA sequences.

Unlike genetics, which focuses on a single gene, genomics studies the complete DNA of an organism.

---

# Gene vs Genome

| Feature | Gene | Genome |
|---------|------|--------|
| Definition | A specific segment of DNA | The complete DNA of an organism |
| Function | Produces a protein or functional RNA | Contains all genetic information |
| Size | Small portion of DNA | Entire DNA content |
| Example | TP53, BRCA1, EGFR | Human Genome |

### Easy Memory

- **Gene = One chapter in a book**
- **Genome = The entire book**

---

# What is Genome Size?

Genome size is the **total amount of DNA** present in an organism's genome.

It is usually measured in:

- Base pairs (bp)
- Kilobase (kb)
- Megabase (Mb)
- Gigabase (Gb)

### Common DNA Units

| Unit | Value |
|------|--------|
| 1 kb | 1,000 bp |
| 1 Mb | 1,000,000 bp |
| 1 Gb | 1,000,000,000 bp |

---

# Human Genome Size

| Feature | Value |
|---------|--------|
| Organism | Homo sapiens |
| Genome Size | Approximately 3.2 Gb |
| Chromosomes | 23 pairs (46 total) |

---

# Key Takeaway

A **gene** is a specific DNA segment with a particular function, while a **genome** is the complete DNA of an organism. The human genome contains approximately **3.2 billion base pairs** across **23 chromosome pairs**.
