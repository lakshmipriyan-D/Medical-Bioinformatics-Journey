# Day 33 – UniProt Quick Revision

## What is UniProt?
UniProt is a database that provides information about proteins, including their function and amino acid sequence.

## Key Concepts

| Concept | Meaning |
|---|---|
| Accession | Unique protein record identifier |
| Reviewed (Swiss-Prot) | Manually reviewed protein record |
| Function | Describes what the protein does |
| Sequence | Amino acid sequence of a protein |
| Isoforms | Different versions of a protein produced from the same gene |
| Similar Proteins | Helps identify related proteins |
| InterPro | Identifies protein families, domains, and functional regions |

## Example: TP53

- **Organism:** Homo sapiens
- **Accession:** P04637
- **Protein:** Cellular tumor antigen p53
- **Length:** 393 amino acids

## Key Takeaway
UniProt helps researchers explore protein identity, function, sequence, and related protein features.
