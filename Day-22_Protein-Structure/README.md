# Day 22 – Protein Structure

Protein structure describes how a protein is organized in different levels.

## 1. Primary Structure

The **primary structure** is the linear sequence of amino acids in a protein.

Example:
`MEEPQSDPSV...`

## 2. Secondary Structure

The **secondary structure** describes local folding of the protein chain.

Main types:
- Alpha helix
- Beta sheet

## 3. Tertiary Structure

The **tertiary structure** is the complete 3D shape of a single protein chain.

## 4. Quaternary Structure

The **quaternary structure** occurs when two or more protein chains come together to form a functional protein complex.

## Key Takeaway

Primary → amino acid sequence  
Secondary → local folding  
Tertiary → complete 3D structure  
Quaternary → multiple protein chains
