# Day 13 – Human Genome Basics

## Human Genome

The human genome is the complete set of genetic information present in a human.

## Human Genome Basics

- Human genome contains about **3 billion base pairs** of DNA.
- Humans have **23 pairs of chromosomes**.
- There are approximately **20,000 protein-coding genes**.
- DNA contains four bases: **A, T, G, C**.
- The genome contains both **coding and non-coding regions**.

## Before the Human Genome Project

Before the Human Genome Project, scientists did not have a complete reference sequence of the human genome.

The Human Genome Project was started to determine and map the complete human genome sequence.

## Key Takeaway

Understanding the human genome is the foundation for studying genes, variants, diseases, and bioinformatics databases.
