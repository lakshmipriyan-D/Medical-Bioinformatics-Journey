## Key Concepts

### Biology
Biology is the study of living organisms.

### MRS GREN
Used to identify whether something is a living organism.

### Cell
- Smallest living unit
- Human body has approximately 37 trillion cells.

### Cell Organelles

| Organelle | Function |
|-----------|----------|
| Nucleus | Control center containing DNA |
| Cell Membrane | Controls entry and exit |
| Cytoplasm | Jelly-like working area |
| Mitochondria | Produces ATP energy |
| Ribosome | Produces proteins |
| Rough ER | Protein transport |
| Smooth ER | Lipid production |
| Golgi Apparatus | Receives, modifies, sorts and packages proteins |
| Lysosome | Cleans waste and destroys bacteria |

## DNA → Protein Flow

DNA → mRNA → Ribosome → Rough ER → Golgi → Protein
